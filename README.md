# Project Overview
UNIQ-CUTZ is a beauty salon established in 1999. This website was designed to showcase the business' services and provide information regarding the business.
# Website Goals and Objectives
•	Provide customers with efficiency to navigate the website with ease.
•	Increase awareness of our business
•	Display our services and reviews of people who have experienced the services
# Key Features and Functionality
Home Page: This page is the introduction to the website that contains a navigation menu and a hero shot image.
About Page: This page contains the organization vision statement, mission statement and the organization brief history.
Enquiries Page: This page contains a form that the user fills in to make an enquiry to the business.
Services Page: This page contains the organizations services that they offer and the various prices along with them.
Contacts Page: This page contains the organizations social media handles and the contact details including the location of the salon.
Gallery Page: This page contains the organizations images and all their descriptions of the services rendered.
